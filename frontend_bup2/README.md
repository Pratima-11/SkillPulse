# SkillPulse Frontend

React + Vite frontend for SkillPulse.

## Run

```powershell
npm install
npm run dev
```

Set `VITE_API_BASE` in `.env` if the Flask backend is not running at `http://localhost:5000/api`.

The existing landing-page visual language is preserved. Functional additions include live job/stat loading, authentication, worker and contractor dashboards, job application, job posting, availability/skill updates and live matching results.
